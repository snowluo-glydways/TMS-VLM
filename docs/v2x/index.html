V2X public test: pedestrian detection on 200 roadside images (2× upscaled)

The same three Qwen3.8-27B methods as the TMS demo, run on the public Constellation dataset (high-elevation intersection cameras, NYC). Each 832×832 image is enlarged 2× before it is sent to the model. Thin cyan boxes in the images are the ground truth.

Accuracy and latency

A prediction counts as a hit when its center falls inside a ground-truth box (“center”). This avoids penalizing a box-drawing difference: the dataset draws pedestrians as roughly square boxes about twice as wide as the person, while the model draws tight body boxes.
