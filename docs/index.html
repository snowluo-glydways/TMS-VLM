Methods. Baseline: plain vLLM, the model writes JSON {"bbox_2d","label","confidence"} per pedestrian (~300 tokens). MTP: same prompt, multi-token-prediction speculative decoding (3 draft tokens), so the output is the same but decodes ~2.6× faster. JEV (+MTP): the model writes only box coordinates (~135 tokens); each box is then checked with a 1-token “is this a pedestrian? Yes/No” question that reuses the cached image prefix and runs in parallel; the score is P(Yes). Box coordinates use Qwen's 0–1000 scale; greedy decoding, thinking off, frames resized to 1920 px wide.
